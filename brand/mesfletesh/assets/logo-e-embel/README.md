# Logo «E ëmbël»: kualitet maksimal

Të gjitha SVG-të kanë germat të kthyera në vija (outlined), pra hapen njësoj kudo (Canva, Figma, Illustrator, shtypshkronjë) pa pasur nevojë për fontin. SVG-ja është vektor: mund të zmadhohet pa limit, edhe për billboard ose stampim.

| Skedari | Përdorimi |
|---|---|
| `logo-sfond-gjalpe` | Logo kryesore me tagline, mbi gjalpë (6000 px) |
| `logo-sfond-roze` | E njëjta mbi rozë (6000 px) |
| `logo-sfond-cokollate` | E njëjta mbi çokollatë, për story të errëta (6000 px) |
| `logo-me-tagline-cokollate` / `-krem` | Me tagline, sfond transparent (6000 px) |
| `wordmark-cokollate` / `-krem` | Vetëm «mes fletësh», transparent (6000 px) |
| `wordmark-bardhezi` | E zezë e plotë: faturë, stampim, gravurë |
| `foto-profili-gjalpe` | Foto profili për IG/TikTok (3000 × 3000) |
| `monogram-mf-roze` / `-transparent` | Monogram për stickers, vulë, favicon (3000 px) |

Ngjyrat: Çokollatë #3B2A20 · Koral #D9735B · Gjalpë #F6E7C1 · Rozë pluhuri #E8B4B0 · Krem #FFFAF2
Fontet burimore: Fraunces (opsz 144, wght 430, SOFT 100, WONK 1) · Caveat 500
